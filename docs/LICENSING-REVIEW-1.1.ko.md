## 사용 사례 대조

아래는 새 허락을 적용하는 자료에 대한 문언 대조다. 이전 허락·플랫폼 약관·법률상 예외가 있으면 그 범위를 별도로 판단한다. 법원이 실제 사건의 상업성이나 저작물성을 판단한 결과를 뜻하지 않는다.

| 사례 | 정리한 결과 | 근거 |
|---|---|---|
| 개인의 비상업적 학습과 비공개 코드 수정 | 허용 | 코드 3(a)·(b) |
| 고지·해당 버전 조건을 동봉한 비상업적 원본 미러 | 허용 | 코드 3(c), 4항 확인 문장 |
| 원본의 변경 없는 일부 파일·발췌·컴파일본 공유 | 비상업적 목적 및 관련 고지 보존 시 허용 | 코드 2·3(c) |
| 무료지만 사업 도입을 위한 PoC | 무료라는 이유로 허용되지 않음; 상업적 목적이면 별도 허락 | 코드 2·4(a) |

## 보존과 검증

변경 전 [코드 1.0](../licenses/401SPAG-NC-ND-1.0.txt)과 [CONTRIBUTING 원문](../licenses/CONTRIBUTING-1.0.txt)을 기준 커밋과 동일한 바이트로 보존한다. 기존 [CC BY 원문](../licenses/CC-BY-4.0.txt), 최초 [기준 파일 목록](licensing/transition-2026-11-14.json), CC BY-NC-ND 공식 법률문은 수정하지 않는다. 새 버전 표시가 과거 조건을 강제로 대체하는 것은 아니다.

TRACE-DM manifest의 문서 등록·해시·크기, 전체 회귀 테스트, wheel·sdist의 조건·역사 기록 동봉과 배포 메타데이터를 확인한다. 이 기계적 검증은 법률 해석을 자동 검증하지 않는다. 사용 사례 표는 조항 간 일관성에 대한 수동 검토이며, 실제 테스트·게시 증적은 연구 세션 TRACE-DM에 보존한다.

## 남는 법적·운영적 한계

- 과거 공개분의 권리 사슬, 제3자 기여, 실질적 상업성·저작물성은 자료와 이용 사례별로 확인해야 한다. 현재 저장소의 표시만으로 전부 확정하지 않는다.
- 실제 계약에는 권리자·대리 권한·계약 상대방을 특정해야 한다. 이 개정은 401SPAG의 법인 여부, 법적 명칭, 저작권 양도 사실을 만들어 내지 않는다.
- 공개 플랫폼의 별도 약관상 권한은 NC-ND 고지로 일괄 철회할 수 없다. 2026-11-14 열람한 GitHub 표준 약관 D.4에는 서비스 제공 외 AI 기능·모델 관련 이용 허락도 포함되어 있다. 실제 계정에 적용되는 약관·추가 계약 범위를 확인해야 하며, 모든 상업적 재사용을 저장소 라이선스만으로 차단했다고 주장하지 않는다.
- 코드 허락은 특허 라이선스를 포함하지 않는다. 면책·책임 제한·동의·철회·준거법 및 관할의 실제 효력은 적용 법과 사건에 따라 달라질 수 있다. 별도 상업 계약 전 독립 법률 검토가 필요하다.
